# 🚌 Cloud-Based Bus Pass System (CodeAlpha Internship - Task 3)

📌 Overview

This project is a **cloud-based Bus Pass / Ticket Booking System** built using Flask and deployed using ngrok.  
It demonstrates backend development, API creation, and cloud deployment in a simple booking system.

🚀 Features

- Simple web-based bus pass system
- Home page displaying system status
- Ticket booking API (sample implementation)
- View booked tickets (JSON response)
- Cloud deployment using ngrok (public access)

🛠️ Tech Stack

- Python
- Flask
- pyngrok
- Google Colab

🌐 Live Deployment

The application is deployed using ngrok and accessible via:

👉 https://flight-panther-plant.ngrok-free.dev

📡 API Endpoints

- `/` → Home page (System status)
- `/book` → Book a sample ticket
- `/tickets` → View all booked tickets

🧪 How It Works

1. Flask server runs on port 5000
2. ngrok exposes local server to the internet
3. Users access system via public URL
4. Tickets are stored temporarily in memory

📚 Learning Outcomes

- Flask backend development
- REST API creation
- Cloud deployment using ngrok
- Handling HTTP routes and requests
